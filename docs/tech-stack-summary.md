# FitFlow Technology Stack Summary

- Frontend: React Native + React Native Web
- Backend: Node.js/NestJS (core services), Python/FastAPI (AI microservice only)
- Primary database: PostgreSQL (structured, compliance-sensitive data)
- Real-time/social database: Firebase Firestore / Realtime Database
- Authentication: Firebase Auth
- AI/Computer Vision: TensorFlow Lite, ML Kit

Full justification, comparison tables, and the weighted decision matrix are documented in
Lab Exercise 05 – "Technology Selection and High-Level Architecture Design for the FitFlow Application".
